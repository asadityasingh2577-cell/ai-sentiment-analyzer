# AI-Based Sentiment Analyzer

**Stack:** Python, Flask, Transformers (Hugging Face), MongoDB

## Overview
This project analyzes text (reviews or social media posts) to determine sentiment: Positive, Negative, or Neutral.  
It stores results in MongoDB and visualizes a summary on the web dashboard using Flask.

## Quick Start
1. Clone repo:
2. Create virtualenv & install dependencies:
3. Start MongoDB (locally or via Docker):
4. Copy `.env.example` to `.env` and adjust settings if needed
5. Run the Flask app:
6. Open browser at `http://127.0.0.1:5000` to enter text and see sentiment results.
